# FeeloWall New Tab Extension

Shows a wallpaper from the featured list, or from a public collection, on every new tab. Works in Chrome, Edge, and other Chromium browsers.

## Try it locally

1. Go to `chrome://extensions` (or `edge://extensions`) and turn on **Developer mode**.
2. Choose **Load unpacked** and select this `extension` folder.
3. Open the extension's **Details → Extension options**, enter your FeeloWall server address, and save. The browser asks permission to reach that one address.
4. Open a new tab.

To publish it, zip this folder's contents and upload to the Chrome Web Store, which charges a one-time developer fee and reviews each submission.

It only reads public data, so it needs no account and stores no credentials.
